About MediaFlow

MediaFlow is a local Flask application built around yt-dlp and FFmpeg. Platform extraction behavior can change over time; a JavaScript runtime may be required by yt-dlp for some current YouTube extraction paths.

Use the application responsibly and only download media you have permission to download.
